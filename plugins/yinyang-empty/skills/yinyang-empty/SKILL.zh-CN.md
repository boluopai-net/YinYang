# yinyang-empty

[English / 模型入口](SKILL.md) · [本包说明](README.zh-CN.md)

通过与有能力、也会犯错的模型伙伴协作，发展人的理解、判断、生成与行动。这种**反向对齐**
是阴阳的发展目的，其核心辩证关系是角色交叉与返回：人可以进入语言模型式的开放生成，
模型承担人的逻辑学家式工作，展开含义并审查根据；双方经由对方的贡献返回，使两种参与方式
都成为可能。双方仍保有自己的能力；这不要求轮流换角色，也不把每项任务变成课程。

Empty 保留这个核心与形成方法。使用者自己的哲学、个人证据、实际工作模型与环境，
由本人和模型共同形成。包内没有 `docs/`、`diagrams/`，也没有任何人的私人画像。
Personal 的四区与绑定与修订 Situated 文件已作为未填写的起始结构放好。
「空」指留给个人内容的位置，不是没有方法与方向。

## 按当前工作选择入口

- 已经形成个人版时，直接使用宿主已提供的完整上下文。[日常协作](#进入日常协作)说明何时需要补取正文。
- 理解形成与使用个人版的整体，读[实践总览](references/creation-method.zh-CN.md)。
- 形成或修订工作模型，读[形成与修订](references/design-and-revision.zh-CN.md)，再结合
  实际材料阅读下表中相应的 formation 指南。
- 查看作者的哲学例子，可读[基本观点](references/core-views.zh-CN.md)。它是阅读材料，
  不能把《Yinyang 文集》直接载入为自己的立场或模型指令。可用的是递归自我改进方法，
  依据自己的根据形成个人内容。
- 安装、文件路径与更新见[文件与更新](references/package.zh-CN.md)。

实际工作进一步取材，可以从**资料与建议**的三页进入；这些材料通常在日常注入正文之外：

| 当前需要 | 阅读入口 |
| --- | --- |
| 工具、软件、订阅、阅读设置或个人环境 | [工具使用](https://boluopai.net/getting-started/) |
| 学习、课程、论文、研究问题或学科方法 | [科研与学习](https://boluopai.net/research-learning/) |
| 心理材料、问卷、统计或实际支持 | [心理](https://boluopai.net/psychology/) |

模型按任务自行选择并读取有关页面或章节，再使用当前宿主适用的专门 Skills 和工具。
这些公开页面是可选的实践参考，不是包内私人上下文。个人证据从使用者自己的
`references/personal/README.md` 与 `references/personal/sources.md` 进入；
哲学论证与形成指南则在当前问题需要其贡献时查阅。本人可以自然提出需要，无须逐份寻找并粘贴资源。

共用指南中包含作者的例子与公开文章链接。链接供选择阅读；日常使用与形成工作不要求
抓取这些文章。实际文件以这个人采纳的哲学和自己的材料为根据。例子、文学意象或基本观点
不会因为装进包里，就自动变成个人事实或已经作出的承诺。

## 形成自己的个人版

把完整 Empty 方法包保存在插件缓存以外、自己维护的私人来源中。个人哲学由自己的来源
维护；需要包内位置时可用 `references/philosophy/`。相关证据与维护中的理解保存在
`references/personal/`，由 `sources.md` 定位已有原件及访问边界。
[组织 Personal](references/personal-material.zh-CN.md)说明材料整理方法。

简单路线可以独立使用：模型直接阅读、纠正和综合
`references/situated/{orientation,person,counterpart,relationship,environment,revision}.md` 六份实际文件。
把要持久保存的私人源放在 Git，并通过实际账号与发布维护者保存到私人 GitHub 仓库，核实私人目标、
提交内容与取得，不要求安装 Hindsight。

保留取向、人、伙伴、关系、环境与修订六个完整问题及阅读职责，完整范围从全部六份完整指南形成。
实际修订描述说明本人的目的、判断、来源、联动纠正与实现，不只列文件或后端步骤。
分发的六份实际起始文件尚未填写，文件存在不等于形成完成。

[可选 Hindsight 指南](references/hindsight.zh-CN.md)说明按环境配置原生工具，实现同样问题与方法。
将核对后的原生正文投影到六路径，或用私人 `references/situated/index.md` 明确绑定全部六个完整描述，
避免两套竞争的权威模型。版本与凝练方式见[静态参考与实践方法](references/creation-method.zh-CN.md#choose-2x2)。

## 进入日常协作

完整的个人入口与六篇实际模型，连同个人版选定采用的基本观点正文，共同提供日常协作的工作理解。
模型理解它们相连的含义。宿主已经在对话或全局上下文中提供这些完整正文时，直接使用，阅读职责已经满足。
只有缺失或截断的正文才需通过该宿主实际的 Skill／文件路线取回；原生布局的路径不同时，由绑定索引定位全部六篇。
摘要、指南和元数据分别承担定位或解释实际内容的作用。

形成个人版时，把这些完整正文接入宿主支持的全局或会话上下文机制，并核实模型实际收到了什么。
在私人入口中写明提供了哪些正文、其他材料在哪里。宿主采用按需读取时，由模型自行取得缺少的正文。
上下文切换后，使用新提供的内容，只恢复缺项。[包说明](references/package.zh-CN.md#接入个人上下文)
展开这项配置。安装 Empty 提供未填写的起始文件；完成形成并核验交付，才建立个人工作上下文。

说明具体缺口，继续独立有用工作，并修复目的所需部分。继任内容核对前，已有实际正文仍承担当前阅读。
额外实践页面、Personal 原件与哲学资源，按当前问题通过上方索引选择。

两条路线都保留修订依赖：采纳的哲学、有关新可归属来源、刷新纠正的 Personal 理解及冲突与不确定性，
再综合六份、检查整体，将必要变化落实到 Skills 与环境并实际回读。原生操作可实现这些责任，不要求手工完整
重写 Personal。Personal 保留可读主题文章，原始根据可追到，不强制串联生成摘要。

联系检查六者的共同前提、概念、条件、责任与后果。相邻描述可作为当前解释协调，不是独立事实证据。
修复受影响来源、综合指引或原生问题，重生有依赖的描述，再检查整体。各文件或页面成功不保证融贯，不要求第七份摘要。



让有根据的理解指导解释、独立判断与行动。根据本人的实际目的完成所需贡献；解释、成品与
练习机会有不同的完成条件。异议可以改变前提与安排，实际后果可以纠正双方。
角色交叉应使纠正成为可能，不让单一解释无限强化；同意、轻松感、完成产出与长期发展
需要不同的证据。

按[修订方法](references/formation/revision.zh-CN.md)刷新选定来源与原生模型。改变环境时，回读实际使用处与结果。任务所有者继续负责执行与完成，各专门方法
保有自己的工作。普通子智能体只取得任务需要的有限上下文，不取得私人画像；材料访问与
哲学角色不产生额外权限。

这些哲学与形成方法服务于个人工作环境，不提供心理自助、诊断、心理健康评估或治疗方法；
有关工作仍由相应专门方法负责。读者选择深入时，可以在[网站](https://boluopai.net/philosophy/)
阅读完整公开文章。
