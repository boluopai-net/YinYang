# yinyang-empty

**保留反向对齐、阴阳辩证法与形成方法，形成自己的哲学与个人版。**

[English](README.md) · [日常协作](SKILL.zh-CN.md) · [哲学文章](https://boluopai.net/philosophy/)

Empty 包含六份 formation 指南、作为作者建议的基本观点、实践总览、形成与修订、
日常协作和 Personal 整理指引。不含 `docs/` 与 `diagrams/`；作者展开的文章和图示
保留在网站上，供选择阅读。

本方法保留反向对齐，以及角色交叉与辩证返回这个核心。其他建议不会因为安装就自动
成为你采纳的哲学。自己的哲学、个人材料与按问题形成的工作模型，根据本人的目的、经验、
来源和环境，与模型共同形成。模型可以承担写作和实现，不要求你独自完成。

本包是 **Empty**，提供自己的实践所用的递归自我改进方法。
[实践总览](references/creation-method.zh-CN.md#choose-2x2)说明直接凝练与辅助凝练；作者的哲学文章作为可选阅读材料。
包内的六份 `status: unfilled` 起始文件、四个空 Personal 分区与来源索引，
供你和模型形成自己的内容；文件位置见[文件与更新](references/package.zh-CN.md)。

[Codex 安装说明](https://github.com/boluopai-net/Yinyang/blob/main/docs/codex.zh-CN.md)
提供 `yinyang-empty@boluopai`，自己的实践使用这一方法包。个人内容保存在会被替换的
插件缓存之外。公共方法更新保留你自己的内容，哲学文章保持为独立阅读材料。
